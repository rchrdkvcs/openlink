# Invite links instead of email invitations

Openlink replaces per-email invitations entirely with shareable invite links: a workspace can hold several revocable links, each carrying a role (Admin, Editor, or Viewer) plus an optional expiration date and usage limit. Openlink is self-hosted first (ADR 0003) and many instances run without a configured mailer, so an email-based invitation path is unreliable as the only door into a workspace; a copyable link works everywhere and matches how small teams actually share access. We accept the trade-off that invitations are no longer nominative — control comes from scoping links (role, expiry, usage limit) and revoking them, not from addressing a specific inbox — and that the previously documented `POST /api/v1/invitations` email contract is rewritten rather than preserved.
