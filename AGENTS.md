# Agent Guidance

## Code comments

Keep all tracked code, configuration, templates, and scripts free of comments, including PHPDoc and inline annotations. Express intent through names, types, tests, and documentation outside source files. Remove existing comments when editing a file.

## Agent skills

### Issue tracker

Issues and PRDs are tracked as GitHub issues; external PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

This repo uses the default triage label vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo with domain language in `CONTEXT.md` and ADRs in `docs/adr/`. See `docs/agents/domain.md`.
