# Manage connected identities from profile

Openlink will let users manage connected identities from the profile page, including linking and unlinking configured OAuth providers, while always retaining at least one valid sign-in method. A connected identity is a valid sign-in method only while its verified provider email matches the user's verified email; identities can remain visible after an email change without being usable for sign-in. Valid connected identity avatars may be selected as the user's profile avatar, and if the selected identity is removed or becomes invalid Openlink will choose another available valid connected identity avatar or fall back to initials. This revises the first OAuth increment from ADR 0009, where provider avatars were stored only on connected identities and manual profile management was deferred.
