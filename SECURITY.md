# Security Policy

## Supported versions

Openlink has not published a stable release yet. Security fixes are applied to
the latest release and the default branch; older versions are not supported.

## Reporting a vulnerability

Do not open a public issue or pull request for a suspected vulnerability.
Instead, use
[GitHub's private vulnerability reporting](https://github.com/rchrdkvcs/openlink/security/advisories/new).

Include the affected version or commit, reproduction steps, potential impact,
and any suggested mitigation. You should receive an acknowledgement within
seven days. Please allow time for investigation and a coordinated fix before
disclosing the issue publicly.

Never include real credentials, personal data, or data from systems you do not
own in a report.
